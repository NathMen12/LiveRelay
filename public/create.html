Partagez votre écran, activez le micro si besoin, puis diffusez. Le serveur relaie le flux à tous les spectateurs.

Le mode direct utilise la piste d'écran telle quelle : plus fiable quand l'onglet hôte passe en arrière-plan. Le mode canvas force la résolution demandée mais peut geler si l'onglet hôte n'est plus visible.

Chrome ou Edge sur ordinateur recommandé. getDisplayMedia exige HTTPS ou localhost. Le partage d'écran s'effectue dans la fenêtre de votre navigateur.
